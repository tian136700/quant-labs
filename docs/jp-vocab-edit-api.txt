日语抽问 · 编辑词条 API（老师端编辑弹窗 / 其它项目写回）
========================================================

用途
----
一次性更新日语词库某条词条的可编辑字段（单词或语法）：
读音、释义、词性、备注、例句、用法、接序、相关构词、助记等。

网页主路径：`/jp-vocab` 编辑弹窗 → POST 本接口。
改用法时服务端会校验语法用法格式（中文、编号、句末 (N5)/(N4)…）；
接续请写在 `connection`，不要塞进 `usage`。
本次提交了非空 `example_sentences` 时，会先做格式规范化（剥掉
「译文：訳文：…」叠日文标签、「译文：/ …」等），再走与补全相同的例句校验
（拒 ～占位、漏假名、译文夹日语、死译壳、間假句、注意する误用を、
相談する に/と 译文对调等；通过后写回规范化文本）。
未剥净、或仍含「訳文：」的脏输入在校验阶段会拒（`gloss_has_yakuwen_label`）。


线上地址
--------
POST https://japanese.info-quests.com/api/jp-vocab/edit

说明：也可用 `finance.info-quests.com` 同路径（同一 Worker / 同一 D1）。


本机开发（可选）
---------------
POST http://127.0.0.1:3002/api/jp-vocab/edit


鉴权
----
须登录 Cookie 会话，且具备日语词库写权限（`requireJpVocabAccess`：
operate / teacher / admin 等）。

Header：
  Content-Type: application/json
  Cookie: <登录会话>
  x-locale: zh | en   （选填；影响错误文案语言）

特殊：
- 字段 `mnemonic`（助记）**仅管理员**可写；非管理员传该字段 → 403 forbidden。
- 非管理员响应里的 mnemonic 会被脱敏（redact）。


请求体
------
{
  "word_id": 123,                 // 必填，正整数
  "kind": "word",                 // 选填：word | grammar
  "word": "真面目",                // 选填；改词条正文
  "reading": "まじめ",             // 选填；grammar 会忽略/置空
  "meaning": "认真；老实；正经",    // 选填
  "pos": "な形容词",               // 选填
  "class_notes": "…",             // 选填；空串存 NULL
  "example_sentences": "…",       // 选填；空串存 NULL；老师手改来源记「手动」
  "usage": "1. ……。(N5)",         // 选填；语法用法（见下）
  "connection": "一类形容词原形＋…", // 选填；接序/接续
  "related_compounds": "…",       // 选填；相关构词（仅单词；见下）
  "mnemonic": "…"                 // 选填；仅管理员
}

说明：
- 只传要改的字段即可（未传字段保留库中原值）。
- な形容词辞书形「〜だ」：改 word/reading 时会剥成词干入库。
- 手改 meaning / pos / example_sentences / usage / connection /
  related_compounds 时，对应 `*_source` 会记为「手动」
  （除非另行走 fill 接口传 source）。
- `example_sentences` 存库格式仍为「日语行 + 译文：…」括号假名；
  页面展示另转下方小字，勿改成 ruby HTML。
- `related_compounds`：多行「漢字(かな)：中文」；卡片在例句后展示「相关构词」。
  语法词条请留空；没有自然相关词就不要硬凑。

语法 usage 校验（非变形课）
--------------------------
kind=grammar 且词条**不是**「变形/变化规则」类活用课时，若本次写入了
非空 `usage`，须通过与补全相同的校验：

- 中文说明（「」内可短引日语形态）
- 用 `1. 2. …` 编号
- 每条句末半角等级括号，如 `(N5)` / `(N4)`
- 用法正文**不要**写「接在…」「构成「…＋…」」等接续句 → 请放 `connection`

变形课（词条名含变形/变化规则等）不强制 usage。


例句 example_sentences 校验（本次提交了非空时）
---------------------------------------------
与 `POST /api/jp-vocab/fill-example-sentences` apply 同源校验
（`validateJpVocabExampleSentencesAiOutput`）。保存前会先
`normalizeJpVocabExampleSentencesFormat`（剥叠标签）。常见硬性要求：

- 日语行：汉字旁半角 `漢字(かな)`；句中汉字须全覆盖假名
- 每条下一行：只用中文标签 `译文：` + 自然中文
  - ❌ 禁止日文「訳文：」或「译文：訳文：…」叠标签（规范化会剥；
    仍残留则拒 `gloss_has_yakuwen_label`）
  - ❌ 禁止译文夹日语假名 / 日语句（`gloss_not_chinese`）
  - ❌ 禁止死译壳（`literal_chinese_gloss`）：
    「关于…说话」；「安静地说话／讲话」（静かに話す → 请小声说话）
- 禁止例句里保留词典占位 `～` / `〜`（`lemma_placeholder_in_sentence`）
- 须有句末标点；语法例句须用到该语法点
- 一类形容词过去式禁止叠「でした」（`i_adj_past_deshita`：
  ❌面白かったでした → ✅面白かったです）
- 「間／あいだ」假句与误译：
  - ❌忙しい間です／我现在很忙 → `aida_fake_state_predicate`
  - ❌の間に…译成「……后」→ `gloss_aida_ni_as_after`
- 「注意する」小心某事须接「に」（`chuui_suru_wo_particle`：
  ❌約束を注意 → ✅約束に注意）
- 「好き／嫌い」对象须接「が」（`suki_kirai_wa_particle`：
  ❌魚は嫌いです → ✅魚が嫌いです）
- 「相談する」に／と 译文须对齐（`soudan_particle_gloss_mismatch`）：
  人に＝向/找某人商量；人と＝和某人一起商量（勿对调）
- 条数不够 / 块格式不完整会拒（need_more_japanese_lines / need_four_lines）

未传 `example_sentences`、或传空串清成 NULL：不走上述校验。

样例（正确）：
  今日(きょう)は大変(たいへん)寒(さむ)いです。
  译文：今天非常冷。

  静(しず)かに話(はな)してください。
  译文：请小声说话。

  車(くるま) に 注意(ちゅうい)します。
  译文：小心汽车。

样例（错误，勿写）：
  今日(きょう)は大変(たいへん)寒(さむ)いです。
  译文：訳文：今天非常冷。

  静(しず)かに話(はな)してください。
  译文：请安静地说话。

  約束(やくそく) を 注意(ちゅうい)してください。
  译文：小心你的承诺。


接序 connection（选填）
----------------------
多用法且接续不同时，请用「用法1:」「用法2:」分行对应；
禁止用裸「1. 2. 3.」给接序编号（会整段挂到用法1下）。
各用法接续相同时，可只写共用形态一段。
保存时会 `normalizeJpVocabConnectionText`（含裸编号改写成「用法N:」）。


相关构词 related_compounds（选填，仅单词）
----------------------------------------
助记用：含本词汉字/读音的简单词（口→入口）；连浊算同一读音族。
存库多行，每行：

  入口(いりぐち)：入口
  出口(でぐち)：出口

条数：没有自然相关词 → 空串/不传（禁止硬凑）；少则 1～2；多则最多 4～5。
校验（`validateJpVocabRelatedCompoundsAiOutput`）：
- 语法词条非空 → related_compounds_word_only
- 行格式不对 → related_compounds_bad_line
- 超过 5 条 → related_compounds_too_many
- 与本词无关 → related_compounds_unrelated
- 写成本词自己 → related_compounds_is_self
- 熟语漏连浊（入口标 いりくち）→ wrong_jukugo_furigana

curl -sS -X POST \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'Content-Type: application/json' \
  -H 'x-locale: zh' \

Python 最小示例
---------------
import json
import urllib.request

URL = "https://japanese.info-quests.com/api/jp-vocab/edit"
COOKIE = "你的登录 Cookie"

payload = {
    "word_id": 484,
    "meaning": "认真；老实；正经",
    "pos": "な形容词",
}
req = urllib.request.Request(
    URL,
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Cookie": COOKIE,
        "Content-Type": "application/json",
        "x-locale": "zh",
    },
    method="POST",
)
with urllib.request.urlopen(req, timeout=60) as resp:
    print(json.loads(resp.read().decode("utf-8")))
