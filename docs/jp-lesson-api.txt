日语新课 · 列表与操作 API（含删除）
================================

用途
----
给网页「日语新课」列表、以及其它项目（脚本 / 运维）读写课次：

- GET  拉新课列表 + 教案 refs + **每课笔记条数**（管理员另含老师列表）
- GET  `?view=schedule`  **日程管理轻量列表**（裁剪释义/例句等大字段；手机进页用）
- POST 按 action 改学习状态 / 老师 / 上课时间 / **学习内容+释义** / 记复制次数 / **删除课次**

上传新课（带教案文件）请用专用接口，勿走本路由：
  POST /api/jp-lesson/upload          → docs 见页面「API 上传说明」
  POST /api/jp-lesson/upload-mixed    → docs/jp-lesson-upload-mixed-api.txt

课堂笔记正文（含贴图）不要指望本 GET：列表只返回 `note_counts`，
正文走：GET /api/jp-lesson/notes?lesson_id=（见下文「GET · 按课笔记正文」）。


线上地址
--------
GET  https://japanese.info-quests.com/api/jp-lesson
GET  https://japanese.info-quests.com/api/jp-lesson?view=schedule
POST https://japanese.info-quests.com/api/jp-lesson

说明：也可用 finance.info-quests.com 同路径（同一 Worker / 同一 D1）。


本机开发（可选）
---------------
GET  http://127.0.0.1:3002/api/jp-lesson
GET  http://127.0.0.1:3002/api/jp-lesson?view=schedule
POST http://127.0.0.1:3002/api/jp-lesson


鉴权
----
须登录 Cookie 会话（与站点老师端同权）。

| 操作 | 权限 |
|------|------|
| GET 列表 | 日语新课 · 查看 |
| POST record_link_copy | 日语新课 · 查看 |
| POST delete / 改学习状态 | 日语新课 · 编辑/操作 |
| POST set_teacher / set_class_schedules / set_next_class_at | **管理员** |

Header（可选，影响错误文案语言）：
  x-locale: zh | en


────────────────────────────────
GET · 列表
────────────────────────────────

说明（重要）
------------
为避免 Worker **Error 1102**（CPU/内存超限），列表 **不再** 返回课堂笔记正文：

| 字段 | 含义 |
|------|------|
| note_counts | `{ "<lesson_id>": <条数>, … }`，仅 COUNT，给列表角标 |
| notes       | 恒为 `[]`（兼容旧客户端字段；勿再依赖正文） |

某课笔记正文：`GET /api/jp-lesson/notes?lesson_id=77`（见下一节）。


成功响应（节选）
----------------
{
  "ok": true,
  "lessons": [ { "id", "kind", "content", "course_label", "course_group_id",
                 "progress…", "ref_key", "class_schedules", … } ],
  "refs": { "lesson-77": { "ref_key", "media_type", "updated_at", … }, … },
  "note_counts": { "77": 3, "80": 1 },
  "notes": [],
  "teachers": [ … ]   // 仅管理员
}

非管理员响应里老师 / 上课时间等字段会被清空（防泄露）。


curl 示例
---------
curl -sS 'https://japanese.info-quests.com/api/jp-lesson' \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'x-locale: zh'


Python 最小例（列表）
--------------------
import requests

BASE = "https://japanese.info-quests.com"
COOKIE = "你的登录 Cookie"

r = requests.get(
    f"{BASE}/api/jp-lesson",
    headers={"Cookie": COOKIE, "x-locale": "zh"},
    timeout=60,
)
data = r.json()
assert data.get("ok")
# 角标：某课有几条笔记
print(data.get("note_counts", {}).get("77", 0))
# 注意：JSON 对象的 key 常是字符串 "77"


────────────────────────────────
GET · 日程管理轻量列表（?view=schedule）
────────────────────────────────

用途
----
统一日程页 `/jp-lesson/schedule` 进页拉取。比完整列表更轻，避免手机弱网卡顿：

| 相对完整 GET | schedule 视图 |
|--------------|---------------|
| meanings / annotations / example_sentences | **不 SELECT**（响应里为 null） |
| content | 仅保留前约 12 项预览（逗号分隔；超出加「…」） |
| note_counts | 恒为 `{}`（日程不用角标） |
| notes | 恒为 `[]` |
| refs | 仅需 `ref_key` + `updated_at`（其它字段占位） |
| teachers / class_schedules / 进度 | **保留**（日历合并与选教材需要） |

**不要**把本响应写入完整新课列表的客户端缓存键（`jp-api:lesson:v*`）；
日程页使用独立键 `jp-api:lesson-schedule:v1`。


查询参数
--------
  view=schedule   必填（其它值或缺省 → 走完整列表）


成功响应（节选）
----------------
{
  "ok": true,
  "view": "schedule",
  "lessons": [
    {
      "id": 77,
      "kind": "grammar",
      "content": "～ばかり, ～ようになる, …",
      "meanings": null,
      "annotations": null,
      "example_sentences": null,
      "completed": false,
      "learning": true,
      "ref_key": "lesson-77",
      "class_schedules": [ { "id": 1, "class_at": "…", "duration_minutes": 55 } ],
      "teacher_ids": [1]
    }
  ],
  "refs": {
    "lesson-77": {
      "ref_key": "lesson-77",
      "updated_at": "…",
      "title": null,
      "media_type": "pdf",
      "r2_key": "",
      "created_at": ""
    }
  },
  "note_counts": {},
  "notes": [],
  "teachers": [ … ]   // 仅管理员
}

────────────────────────────────
POST · 通用约定
────────────────────────────────

Content-Type: application/json

公共字段：
  action      见下表（改学习状态时可省略，见「改学习状态」）
  lesson_id   正整数课次 id（必填）


action 一览
-----------
| action | 谁可调 | 作用 |
|--------|--------|------|
| （省略或只传 progress） | 有编辑权 | 改学习状态 pending/learning/completed |
| delete | 有编辑权 | **删除该课次**（不可恢复） |
| record_link_copy | 有查看权 | 教案链接复制次数 +1 |
| set_teacher | 管理员 | 设置上课老师 |
| set_class_schedules | 管理员 | 设置多段上课时间 |
| set_next_class_at | 管理员 | 兼容：设单段下次上课时间 |
| set_content | 有编辑权 | 编辑学习内容 + 释义 |
| complete_content_items | 有编辑权 | 熟悉词拆项标完成（拆课 + vocab_sync） |
| sync_to_vocab | 有编辑权 | 已完成课分片同步到日语抽问 |


────────────────────────────────
POST · delete（删除新课）
────────────────────────────────

用途
----
删除一条日语新课（列表「删除」按钮同源）。

网页「编辑学习内容与释义」若**删光最后一项**学习内容，也会调本 action
（整条未完成课从列表消失）；不是 set_content 空串。

副作用：
- 若该课已是「已完成」，先从日语抽问卸掉本课同步过去的词/语法
- 删除本课课堂笔记、老师关联、上课时间
- 若教案 ref_key 没有其它课引用，一并删除 jp_vocab_ref

合传课（同一 course_label 两行）须 **各删一次**（单词行、语法行各一个 lesson_id）。
接口 **不会** 按 course_group_id 级联删除另一侧。


请求体
------
{
  "action": "delete",
  "lesson_id": 75
}


成功响应
--------
{ "ok": true }


失败响应
--------
401  { "ok": false, "error": "请登录后再操作。" }
400  { "ok": false, "error": "lesson_id_invalid" }
404  { "ok": false, "error": "not_found" }
500  { "ok": false, "error": "…" }


curl 示例
---------
curl -sS -X POST 'https://japanese.info-quests.com/api/jp-lesson' \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'Content-Type: application/json' \
  -H 'x-locale: zh' \
  -d '{"action":"delete","lesson_id":75}'


Python 最小例
-------------
import requests

BASE = "https://japanese.info-quests.com"
COOKIE = "你的登录 Cookie"  # 浏览器登录后复制

r = requests.post(

        "Cookie": COOKIE,
        "Content-Type": "application/json",
        "x-locale": "zh",
    },
    json={"action": "delete", "lesson_id": 75},
    timeout=60,
)
print(r.status_code, r.json())

────────────────────────────────
POST · 分片同步到日语抽问（sync_to_vocab）
────────────────────────────────

用途
----
新课标「已完成」后，把词条分批写入 /jp-vocab，避免单次请求 Error 1102。
改 progress_status=completed 时响应带 vocab_sync；前端会自动循环本 action。
若课已是已完成但词未进抽问：先改「学习中」再改回「已完成」即可重跑。


请求 JSON
---------
{
  "action": "sync_to_vocab",
  "lesson_id": 123,
  "offset": 0,
  "limit": 8
}


成功（节选）
------------
{
  "ok": true,
  "lesson_id": 123,
  "total": 64,
  "offset": 0,
  "processed": 8,
  "next_offset": 8,
  "done": false,
  "inserted": 8,
  "updated": 0
}

done=true 时本课同步结束（最后一批会顺带同步课堂笔记，无笔记则跳过）。


改学习状态（completed）时另带
------------------------------
{
  "ok": true,
  "lesson": { … },
  "vocab_sync": { "needed": true, "total": 64, "offset": 0, "chunk_size": 8 }
}


────────────────────────────────
POST · 编辑学习内容与释义（set_content）
────────────────────────────────

权限：日语新课 · 编辑/操作

Body:
  {
    "action": "set_content",
    "lesson_id": 84,
    "content": "～ばかり, ～ようになる",
    "meanings": "（刚刚……）|（变得……）"
  }

说明：
- content / meanings 为入库形态（逗号 / |）；网页编辑弹窗会把成对行拆成此格式后再提交
- 保存后按新 content 项数对齐 annotations、example_sentences
- **content 不能为空**（空会 content_empty）；要删光整课请用 action=delete
- 网页弹窗：删行会立刻 set_content（keepOpen）；删光最后一项改走 delete
- 成功返回 { ok, lesson }


────────────────────────────────
POST · 熟悉词拆项标完成（complete_content_items）
────────────────────────────────

用途
----
未完成/学习中课有多词时，把**已熟悉**的项单独标完成：

- 每个选中项 → **新建一条** `jp_lesson`（只含该词/语法项），状态 **已完成**，出现在「已完成」Tab
- 继承原课 `course_label` / `title` / `kind` / `course_group_id`；**无教案**（`ref_key = null`）
- 不复制老师、上课时间
- 从原课 `content` 剔除对应项；原课词全部标完则 **删除原课**
- 响应带 `vocab_syncs`；客户端须对每个新建课循环 `sync_to_vocab`（每批 8，防 1102）

权限：日语新课 · 编辑/操作（与 set_content 同级）

`item_indexes` 为 **0-based**，对当前库内 `parseLessonContent(lesson.content)` 的下标；
须与已保存 content 一致（网页弹窗有未保存改动时会提示先保存）。


请求 JSON
---------
{
  "action": "complete_content_items",
  "lesson_id": 109,
  "item_indexes": [0, 2]
}


成功响应（节选）
----------------
{
  "ok": true,
  "source_lesson": { "id": 109, "content": "フランスじん, 教授", … },
  "source_deleted": false,
  "created_lessons": [
    { "id": 120, "content": "中国人", "completed": true, "ref_key": null, … }
  ],
  "vocab_syncs": [
    { "lesson_id": 120, "vocab_sync": { "needed": true, "total": 1, "offset": 0, "chunk_size": 8 } }
  ]
}

若原课词全部被标完：
  "source_lesson": null,
  "source_deleted": true


失败 error
----------
| error | 含义 |
|-------|------|
| lesson_id_invalid | lesson_id 非正整数 |
| not_found | 课不存在 |
| lesson_already_completed | 源课已是已完成 |
| item_indexes_empty | 未传或空数组 |
| item_indexes_invalid | 下标越界或非法 |
| invalid_annotation | 标注对齐失败 |
| create_failed / update_failed / delete_failed | 写库失败 |


推荐调用顺序（脚本）
--------------------
1. POST complete_content_items
2. 对每个 vocab_syncs[].lesson_id 循环 POST sync_to_vocab（offset/limit，直到 done=true）
   见上文「分片同步到日语抽问」


curl 示例
---------
curl -sS -X POST 'https://japanese.info-quests.com/api/jp-lesson' \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'Content-Type: application/json' \
  -H 'x-locale: zh' \
  -d '{"action":"complete_content_items","lesson_id":109,"item_indexes":[0]}'


Python 最小例
-------------
import requests

BASE = "https://japanese.info-quests.com"
COOKIE = "你的登录 Cookie"
CHUNK = 8

s = requests.Session()
s.headers.update({"Cookie": COOKIE, "Content-Type": "application/json", "x-locale": "zh"})

r = s.post(
    f"{BASE}/api/jp-lesson",
    json={"action": "complete_content_items", "lesson_id": 109, "item_indexes": [0]},
)
r.raise_for_status()
data = r.json()
assert data["ok"], data.get("error")

for entry in data.get("vocab_syncs") or []:
    lesson_id = entry["lesson_id"]
    offset = 0
    while True:
        sync = s.post(
            f"{BASE}/api/jp-lesson",
            json={
                "action": "sync_to_vocab",
                "lesson_id": lesson_id,
                "offset": offset,
                "limit": CHUNK,
            },
        ).json()
        if not sync.get("ok"):
            raise RuntimeError(sync.get("error"))
        if sync.get("done"):
            break
        offset = int(sync.get("next_offset", offset + CHUNK))

print("created:", [x["id"] for x in data.get("created_lessons") or []])
print("source_deleted:", data.get("source_deleted"))
