日语抽问 · 例句补全 API（给 Mac 定时 / STT / Agent 调用）
========================================================

用途
----
拉取缺例句词条（含 prompt），或把生成好的例句写回 D1。
也可同次写回接序、相关构词（单词助记：口→入口）。
也可运维扫描：缺译义、汉字漏标假名；规范化「译文：」前缀；な形容词剥「だ」。

**禁止在 Worker 内调大模型**——模型在 Mac / 其它项目跑，再经本接口 apply。
线上统一补全（付费）应把 related_compounds 与例句放在**同一次**模型输出里。
临时回填单汉字可用 Mac 任务 `jp-vocab-fill-related-compounds-online`（每分钟 1 条）。

线上地址
--------
POST https://japanese.info-quests.com/api/jp-vocab/fill-example-sentences

说明：
- 也可用 `finance.info-quests.com` 同路径（同一 Worker / 同一 D1）。
- 样例客户端：`scripts/jp-vocab-fill-example-sentences-api.py`
- 临时单汉字相关构词：`scripts/jp-vocab-fill-related-compounds-online-api.py`
  安装：`bash scripts/setup-jp-vocab-fill-related-compounds-online-mac.sh`


本机开发（可选）
---------------
POST http://127.0.0.1:3002/api/jp-vocab/fill-example-sentences


鉴权
----
Header:
  Authorization: Bearer <JP_REVIEW_UPLOAD_TOKEN>

Token 与 jp-review-sync 共用，常见配置：
  ~/.config/info-quests/jp-review-sync.env → JP_REVIEW_UPLOAD_TOKEN


限流
----
与其它日语/英语 fill-* 共用：同一 IP×路径约 ≥5s 一次。
超限返回 429，并带 Retry-After；客户端须等待后重试。


mode 一览
---------
| mode | 说明 |
|------|------|
| list_missing（默认；空 body 亦同） | 拉缺例句；每条含 prompt；响应含 upload_spec |
| list_missing_related_compounds | 拉缺相关构词（默认只单汉字词，如口/手）；含 prompt |
| apply | 写回 updates（有 updates 时自动走 apply） |
| scan_incomplete_gloss | 已有例句但缺中文译义 |
| scan_incomplete_furigana | 已有例句但日语行汉字漏标假名（只读） |
| normalize_gloss_label | 仅为已有译义补「译文：」前缀 |
| normalize_na_adj | な形容词「〜だ」剥成词干（词+读音） |
| catalog | 按内置 N5 词表填空（不覆盖已有） |


公共字段
--------
mode              见上表
dry_run           选填。true=不写库
limit             list_missing：最多返回几条（定时建议 1～15）
kind              list_missing：只拉 "word" 或 "grammar"
source            apply：整批默认来源（单条 updates[].source 优先）
allow_overwrite   apply / 补译义：true 才覆盖已有 example_sentences
validate_format   apply：默认 true（严格校验）；传 false 走线上 normalize
                  （仍拒漏标假名 / 熟语错拆 / 非法括注；略宽其它细则）
updates           apply：数组，见下


apply · updates[] 字段
----------------------
word_id             必填。词条 id
example_sentences   选填。例句全文（日语行 + 「译文：」交替；勿行首 1. 2.）
connection          选填。接序；可与例句同次写回
related_compounds   选填。相关构词（仅单词）；可与例句同次写回，也可单独写回
mark_related_compounds_checked  选填。true=确认无自然相关构词（只写 source，正文空）
source              选填。覆盖整批 source（如「本地 gemma4:26b」「Agent现写」）
example_sentences_source  同 source（兼容旧字段）

说明：
- 至少提供 example_sentences / connection / related_compounds /
  mark_related_compounds_checked 之一。
- 仅传 related_compounds：可补已有例句词条的空相关构词（allow_overwrite 控制覆盖）。
- list_missing_related_compounds：默认 single_kanji_only=true；
  候选条件为相关构词空且 source 未写过。

source 约定：
- Mac / 本地模型：如「本地 gemma4:26b」「Qwen本地」
- Agent 现造句写回：**「Agent现写」**（禁止写「手动」）
- 老师在编辑框保存：系统记「手动」


相关构词 related_compounds（单词）
---------------------------------
存库多行「漢字(かな)：中文」。卡片在例句后展示「相关构词」。

  入口(いりぐち)：入口
  出口(でぐち)：出口

条数：没有自然同读相关词 → 不传/空（禁止硬凑）；少则 1～2；多则最多 4～5。
读音：构词里本字读法须与本词一致（允许连浊くち→ぐち）；禁止不同音读（事=こと 勿写食事的「じ」）。
校验失败时 skipped.reason 含：
  related_compounds_word_only / related_compounds_bad_line /
  related_compounds_too_many / related_compounds_unrelated /
  related_compounds_is_self / wrong_jukugo_furigana（漏连浊）
说明：不同音读行在 validate 时会被丢掉；若全部被丢掉则写成空（算无相关）。


例句存库格式（强制）
--------------------
日语一行，下一行「译文：」+ 中文。句中**每一个汉字**都须半角括号假名：

  先生(せんせい)が文法(ぶんぽう)を説明(せつめい)します。
  译文：老师说明语法。
  彼(かれ)はその理由(りゆう)を説明(せつめい)しました。
  译文：他解释了那个理由。

常见拒收（skipped.reason 含 invalid_format:…）：
  need_four_lines / need_more_lines  行数不够（单词默认至少 2 句=4 行）
  incomplete_kanji_furigana   汉字漏标假名
  wrong_jukugo_furigana       熟语错拆（如 出(で)発(ぱつ) 应为 出発(しゅっぱつ)）
  bad_furigana_paren          非法括注 / 整句尾注
  missing_chinese_gloss       缺「译文：」
  double_wa_topic             单词句叠两个话题「は」
  missing_clause_touten       从句后缺「、」
  missing_sentence_final_punct 缺句末标点
  lemma_placeholder_in_sentence 例句里残留「～」「〜」
  word_not_used / grammar_not_used 未用到词条

条数：释义含 `/` 时按斜杠大义项数；无斜杠固定 2（`；` 近义不是条数）。

validate_format：
- 默认 true → validateJpVocabExampleSentencesAiOutput（严格）
- false → normalizeJpVocabExampleSentencesForOnlineApply（仍拒漏标汉字与熟语错拆）
定时 / Mac 模型写回请保持默认 true；Agent 应急可传 false。

curl 示例
---------
# 拉缺例句
curl -sS -X POST \
  -H 'Authorization: Bearer 你的TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"mode":"list_missing","limit":1,"kind":"word"}' \
  'https://japanese.info-quests.com/api/jp-vocab/fill-example-sentences'

# 扫汉字漏标假名
curl -sS -X POST \
  -H 'Authorization: Bearer 你的TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"mode":"scan_incomplete_furigana"}' \
  'https://japanese.info-quests.com/api/jp-vocab/fill-example-sentences'

# 写回（覆盖已有须 allow_overwrite；默认严格校验）
curl -sS -X POST \
  -H 'Authorization: Bearer 你的TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "mode":"apply",
    "allow_overwrite": true,
    "source":"Agent现写",
    "updates":[{
      "word_id": 464,
      "example_sentences": "先生(せんせい)が文法(ぶんぽう)を説明(せつめい)します。\n译文：老师说明语法。\n彼(かれ)はその理由(りゆう)を説明(せつめい)しました。\n译文：他解释了那个理由。"

Python 最小示例
---------------
import json
import urllib.request

URL = "https://japanese.info-quests.com/api/jp-vocab/fill-example-sentences"
TOKEN = "你的TOKEN"


def call(payload: dict) -> dict:
    req = urllib.request.Request(
        URL,
        data=json.dumps(payload).encode("utf-8"),
        headers={
            "Authorization": f"Bearer {TOKEN}",
            "Content-Type": "application/json",
        },
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=180) as resp:
        return json.loads(resp.read().decode("utf-8"))


# 1) 拉缺
print(call({"mode": "list_missing", "limit": 1, "kind": "word"}))

# 2) 扫漏标假名
print(call({"mode": "scan_incomplete_furigana"}))

# 3) 写回
print(
    call(
        {
            "mode": "apply",
            "allow_overwrite": True,
            "source": "Agent现写",
            "updates": [
                {
                    "word_id": 464,
                    "example_sentences": (
                        "先生(せんせい)が文法(ぶんぽう)を説明(せつめい)します。\n"
                        "译文：老师说明语法。\n"
                        "彼(かれ)はその理由(りゆう)を説明(せつめい)しました。\n"
                        "译文：他解释了那个理由。"
                    ),
                    "related_compounds": (
                        "説明書(せつめいしょ)：说明书\n"
                        "説明会(せつめいかい)：说明会"
                    ),
                }
            ],
        }
    )
)
