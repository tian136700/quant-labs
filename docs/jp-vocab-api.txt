日语抽问 · 熟悉程度 / 同步学生 API
================================

用途
----
老师端抽查卡相关写库接口（网页主路径；其它项目也可按同约定调用）：

1) POST /api/jp-vocab
   勾选熟悉程度（very / normal / weak）→ **只写熟悉程度**，不同步学生

2) POST /api/jp-vocab/share
   把该词同步到学生「今日日语单词」→ **每词今日只成功一次**
   （产品约定：老师点「下一个」/「完成抽查」时再调；已共享则勿重复发）

说明：勾选熟悉程度 **不会** 再自动 shareToStudy。学生端自动弹卡依赖 share 成功
（或学生 peek「查看老师正在抽查的单词」）。


线上地址
--------
POST https://japanese.info-quests.com/api/jp-vocab
POST https://japanese.info-quests.com/api/jp-vocab/share

说明：也可用 finance.info-quests.com 同路径（同一 Worker / 同一 D1）。


本机开发（可选）
---------------
POST http://127.0.0.1:3002/api/jp-vocab
POST http://127.0.0.1:3002/api/jp-vocab/share


鉴权
----
须登录 Cookie 会话（老师 operate / 管理员）。

Header（可选，影响错误文案语言）：
  x-locale: zh | en
  Content-Type: application/json


────────────────────────────────
POST · 勾选熟悉程度（不共享）
────────────────────────────────

请求体
------
{
  "word_id": 123,
  "level": "very"   // very | normal | weak
}


成功响应（节选）
----------------
{
  "ok": true,
  "word": { "id": 123, "word": "…", "last_review_level": "very", … },
  "shared": false,
  "shared_new": false
}

说明：
- 当前实现固定 **不** 在勾选时写入今日共享；`shared` / `shared_new` 一般为 false。
- 勿再假定「勾选 = 已同步给学生」。


失败响应
--------
401  { "ok": false, "error": "…" }     // 未登录
400  { "ok": false, "error": "level_invalid" }
400  { "ok": false, "error": "review_locked" }   // 勾选已满 1 小时等
404  { "ok": false, "error": "not_found" }


curl 示例
---------
curl -sS -X POST 'https://japanese.info-quests.com/api/jp-vocab' \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'Content-Type: application/json' \
  -H 'x-locale: zh' \
  -d '{"word_id":123,"level":"normal"}'


Python 最小例
-------------
import requests

BASE = "https://japanese.info-quests.com"
COOKIE = "你的登录 Cookie"

r = requests.post(
    f"{BASE}/api/jp-vocab",
    headers={
        "Cookie": COOKIE,
        "Content-Type": "application/json",
        "x-locale": "zh",
    },
    json={"word_id": 123, "level": "normal"},
    timeout=60,
)
print(r.status_code, r.json())


────────────────────────────────
POST · 同步给学生（今日共享）
────────────────────────────────

请求体
------
{
  "word_id": 123
}


成功响应（节选）
----------------
{
  "ok": true,
  "word": { … },
  "item": { … }   // 若有，共享列表项
}


失败响应
--------
401 / 403  未登录或无权共享
400  { "ok": false, "error": "word_id_invalid" }
404  { "ok": false, "error": "not_found" }
409  { "ok": false, "error": "already_shared_today" }
     → 今日已共享；产品上视为「不必再发」（网页点下一个会跳过）


curl 示例
---------
curl -sS -X POST 'https://japanese.info-quests.com/api/jp-vocab/share' \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'Content-Type: application/json' \
  -H 'x-locale: zh' \
  -d '{"word_id":123}'


Python 最小例
-------------
import requests

BASE = "https://japanese.info-quests.com"
COOKIE = "你的登录 Cookie"

r = requests.post(
    f"{BASE}/api/jp-vocab/share",
    headers={
        "Cookie": COOKIE,
        "Content-Type": "application/json",
        "x-locale": "zh",
    },
    json={"word_id": 123},
    timeout=60,
)
print(r.status_code, r.json())


推荐调用顺序（对齐老师端抽查卡）
--------------------------------
1. 学生答完 → POST /api/jp-vocab 写熟悉程度
2. 老师点「下一个」→ 若今日未共享 → POST /api/jp-vocab/share
3. 已共享（或 409 already_shared_today）→ 直接进下一词，勿重复 POST share
