日语抽问 · 一键下载全部词条 API（给其它项目比对用）
====================================================

用途
----
把线上日语抽问词库里**已有的全部词条**一次拉下来（只含 id / 单词 / 类型），
方便另一个模块或另一个项目做比对：

- 线上已经有的词 → 不必再制作教案
- 线上没有的词 → 才继续做教案 / 上传

本接口是「整库下载」；若只想查某一个词是否存在，请用：
  docs/jp-vocab-exists-api.txt
  GET /api/jp-vocab/exists?word=…


线上地址
--------
GET https://japanese.info-quests.com/api/jp-vocab/download-all

常用带参：
GET https://japanese.info-quests.com/api/jp-vocab/download-all?kind=word
GET https://japanese.info-quests.com/api/jp-vocab/download-all?kind=word&format=txt

说明：
- 也可用 `finance.info-quests.com` 同路径（同一 Worker / 同一 D1）。
- 默认返回 JSON；加 `format=txt` 可直接保存成文本文件。


本机开发（可选）
---------------
GET http://127.0.0.1:3002/api/jp-vocab/download-all
GET http://127.0.0.1:3002/api/jp-vocab/download-all?kind=word&format=txt


鉴权
----
支持两种方式（二选一）：

1) 登录态 Cookie（老师/管理员可读权限）
2) Bearer Token（推荐给外部项目 / 脚本）

Header:
  Authorization: Bearer <JP_REVIEW_UPLOAD_TOKEN>

token 与现有日语/英语上传、exists 接口共用，取环境变量 JP_REVIEW_UPLOAD_TOKEN。


请求参数（Query）
-----------------
kind     选填。`word` / `grammar` / `any`
         - 不传或传 `any`：下载全部（单词 + 语法）
         - 传 `word`：只下载单词（做教案比对通常用这个）
         - 传 `grammar`：只下载语法

format   选填。`json`（默认） / `txt`
         - `json`：返回结构化列表
         - `txt`：纯文本，一行一条：`单词<TAB>类型`，并带下载文件名


成功响应（format=json，默认）
----------------------------
{
  "ok": true,
  "kind": "word",
  "count": 2,
  "words": [
    { "id": 12, "word": "東", "kind": "word" },
    { "id": 35, "word": "重要", "kind": "word" }
  ]
}

字段说明：
- ok      固定 true
- kind    本次筛选：`word` / `grammar` / `any`
- count   条数
- words   轻量列表（不含释义、例句、备注等大字段，避免拖垮 Worker）
  - id    词条 ID
  - word  词条正文（与库中存法一致，含な形容词词干等）
  - kind  `word` 或 `grammar`


成功响应（format=txt）
---------------------
HTTP 200，Content-Type: text/plain; charset=utf-8
Content-Disposition: attachment; filename="jp-vocab-all-word.txt"（视 kind 而定）

正文示例：
東	word
重要	word
～によると	grammar

说明：列之间是 Tab（\t）；每行末尾有换行。


失败响应
--------
400
  { "ok": false, "error": "kind_invalid" }
  → kind 不是 word / grammar / any

400
  { "ok": false, "error": "format_invalid" }
  → format 不是 json / txt / text

401
  { "ok": false, "error": "请登录后查看单词。" }
  或
  { "ok": false, "error": "Please log in to view vocabulary." }
  → 没有登录态且 token 无效

500
  { "ok": false, "error": "..." }
  → 服务器内部异常


curl 示例
---------
# 1）只下载单词（JSON，打印到终端）
curl -sS \
  -H 'Authorization: Bearer 你的TOKEN' \
  'https://japanese.info-quests.com/api/jp-vocab/download-all?kind=word'

# 2）保存成文本文件（推荐给另一项目做集合比对）
curl -sS \
  -H 'Authorization: Bearer 你的TOKEN' \
  -o jp-vocab-all-word.txt \
  'https://japanese.info-quests.com/api/jp-vocab/download-all?kind=word&format=txt'

# 3）全部（单词+语法）JSON
curl -sS \
  -H 'Authorization: Bearer 你的TOKEN' \
  'https://japanese.info-quests.com/api/jp-vocab/download-all'


Python 最小示例
---------------
import json
import urllib.request

BASE_URL = "https://japanese.info-quests.com/api/jp-vocab/download-all"
TOKEN = "你的TOKEN"

# 做教案比对时一般只要单词：
url = BASE_URL + "?kind=word"

req = urllib.request.Request(
    url,
    headers={"Authorization": f"Bearer {TOKEN}"},
    method="GET",
)

with urllib.request.urlopen(req, timeout=60) as resp:
    data = json.loads(resp.read().decode("utf-8"))

print("ok =", data.get("ok"))
print("count =", data.get("count"))

# 做成集合，方便本地词表差集
online = {item["word"].strip() for item in data.get("words") or []}

# 假设本地候选词：
local_candidates = ["東", "西", "架空テスト語"]
need_lesson = [w for w in local_candidates if w not in online]
print("需要做教案的词：", need_lesson)


比对建议
--------
1. 先对本接口拉一次（kind=word），缓存到本地文件 / 内存 set
2. 另一项目提词后，对每个候选词做 `in online_set` 判断
3. 若只需「有没有」，也可对单个词调 /api/jp-vocab/exists（见 exists 文档）
4. 比对时建议两侧都 trim；大小写一般无关紧要（日语），但请与库中原文一致

注意：
- 本接口**故意不返回**释义 / 例句 / 备注 / 教案图，体积小、不易触发 Worker 1102
- 词条很多时 JSON 仍可能较大，脚本超时建议 ≥60 秒；也可用 format=txt 落盘
- な形容词在线库存的是词干（如「重要」而非「重要だ」），比对时请用词干
