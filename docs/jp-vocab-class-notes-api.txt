日语抽问 · 课堂备注 API（按需拉正文 / 保存）
==========================================

用途
----
词表 / shared / sync **列表不返回备注正文**（只带 `class_notes_present` /
`has_class_notes`），避免贴图备注扫库触发 Worker Error 1102。

要看或改备注正文时：

1) GET  /api/jp-vocab/class-notes?word_id=123
   只读 `id` + `class_notes` + `updated_at` + `class_notes_present`
   （禁止整词覆盖本地列表；须 merge）

2) POST /api/jp-vocab/class-notes
   老师/管理员写回备注（空串会存成 NULL）


线上地址
--------
GET  https://japanese.info-quests.com/api/jp-vocab/class-notes?word_id=123
POST https://japanese.info-quests.com/api/jp-vocab/class-notes

说明：也可用 finance.info-quests.com 同路径（同一 Worker / 同一 D1）。


本机开发（可选）
---------------
GET  http://127.0.0.1:3002/api/jp-vocab/class-notes?word_id=123
POST http://127.0.0.1:3002/api/jp-vocab/class-notes


鉴权
----
须登录 Cookie 会话（credentials: include）。

GET：具备日语词库**读**权限（jp_vocab:read / operate / teacher / admin 等），
     **或** 学生 jp_vocab:study（今日单词页查看备注）。

POST：须 jp_vocab 写权限（operate / teacher 等，同 requireJpVocabAccess）。

Header（可选）：
  x-locale: zh | en
  Content-Type: application/json   （仅 POST）


────────────────────────────────
GET · 按需拉备注正文
────────────────────────────────

请求参数（Query）
-----------------
word_id   必填。正整数词条 id。


成功响应（节选）
----------------
{
  "ok": true,
  "word": {
    "id": 123,
    "class_notes": "……备注正文（可含 ![](/api/jp-vocab/ref/…) 贴图）……",
    "class_notes_present": true,
    "updated_at": "2026-07-31T12:00:00.000Z",
    "word": ""
  }
}

说明：
- 响应里其它词条字段多为占位空值；**只信任** id / class_notes /
  class_notes_present / updated_at。
- 客户端须 `mergeJpVocabWordAfterClassNotesFetch(base, fetched)`，
  禁止 `...fetched` 整词覆盖（会冲掉例句 / 用法）。


失败响应
--------
400  { "ok": false, "error": "word_id_invalid" }
401  { "ok": false, "error": "请登录后查看课堂笔记。" }
404  { "ok": false, "error": "not_found" }
500  { "ok": false, "error": "…" }


curl 示例
---------
curl -sS \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'x-locale: zh' \
  'https://japanese.info-quests.com/api/jp-vocab/class-notes?word_id=123'


Python 最小例
-------------
import requests

BASE = "https://japanese.info-quests.com"
COOKIE = "你的登录 Cookie"

r = requests.get(
    f"{BASE}/api/jp-vocab/class-notes",
    params={"word_id": 123},
    headers={"Cookie": COOKIE, "x-locale": "zh"},
    timeout=60,
)
print(r.status_code, r.json())


────────────────────────────────
POST · 保存备注
────────────────────────────────

请求体
------
{
  "word_id": 123,
  "class_notes": "备注正文；空串或仅空白 → 存 NULL（列表 has 标记为无）"
}


成功响应（节选）
----------------
{
  "ok": true,
  "word": { "id": 123, "class_notes": "…", "class_notes_present": true, … }
}


失败响应
--------
401  { "ok": false, "error": "请登录后再编辑课堂笔记。" }
400  { "ok": false, "error": "word_id_invalid" }
404  { "ok": false, "error": "not_found" }


curl 示例
---------
curl -sS -X POST 'https://japanese.info-quests.com/api/jp-vocab/class-notes' \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'Content-Type: application/json' \
  -H 'x-locale: zh' \
  -d '{"word_id":123,"class_notes":"今日课堂备注"}'


Python 最小例
-------------
import requests

BASE = "https://japanese.info-quests.com"
COOKIE = "你的登录 Cookie"

r = requests.post(
    f"{BASE}/api/jp-vocab/class-notes",
    headers={
        "Cookie": COOKIE,
        "Content-Type": "application/json",
        "x-locale": "zh",
    },
    json={"word_id": 123, "class_notes": "今日课堂备注"},
    timeout=60,
)
print(r.status_code, r.json())
