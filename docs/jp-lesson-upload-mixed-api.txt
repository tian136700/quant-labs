日语新课 · 同一课合传 API（单词 + 语法一次上传，列表仍分开展示）
==============================================================

用途
----
一次请求同时上传「单词课」和「语法课」（可各带教案），例如标日初级上册第 23 课：
- 日语新课列表里仍是 **两条**：类型分别是「单词」「语法」
- 新增「教材」列：两边都显示同一课名，如 **标日初级上册第23课**
- 服务端写入相同的 `course_group_id`，标记属于同一课
- 各自在列表标「已完成」后，分别同步到日语抽问（与旧单传行为一致）
- **教材课次会带到词条**：抽问/带读/学生卡片靠后显示小标签（同一 course_label）

旧接口（只传单词 **或** 只传语法）继续用：
  POST /api/jp-lesson/upload


线上地址
--------
POST https://japanese.info-quests.com/api/jp-lesson/upload-mixed

说明：也可用 finance.info-quests.com 同路径（同一 Worker / 同一 D1）。


本机开发（可选）
---------------
POST http://127.0.0.1:3002/api/jp-lesson/upload-mixed


鉴权
----
Header:
  Authorization: Bearer <JP_REVIEW_UPLOAD_TOKEN>

token 与现有教案 / 日语上传共用（环境变量 JP_REVIEW_UPLOAD_TOKEN）。


与旧 upload 的区别
------------------
| | 旧 upload | 本接口 upload-mixed |
|---|---|---|
| 一次传什么 | 单词 **或** 语法 | 单词 **和** 语法 |
| 列表行数 | 1 条 | **2 条**（word + grammar） |
| 类型列 | 单词 / 语法 | 仍是单词 / 语法（分开） |
| 教材列 | 空（—） | 显示 course_label（如标日初级上册第23课） |
| 教案 | 一个 file | 推荐 word_file + grammar_file 各一份 |


请求体
------

1）multipart/form-data（推荐，可带教案图/PDF）

必填：
  course_label       同一课教材名，如「标日初级上册第23课」
                     （新课「教材」列 + 标已完成后抽问卡片小标签）
  word_content       单词列表，英文/中文逗号或顿号分隔
  grammar_content    语法列表，分隔规则同上

选填：
  title              写入两侧 title；默认等于 course_label
  word_meanings / grammar_meanings           与 content 用 | 对齐
  word_annotations / grammar_annotations     口语常用|考试常用|…（| 对齐）
  word_example_sentences / grammar_example_sentences
                     与 content 用 ||| 对齐；单项「日语 + 译文：」
  word_file          单词教案（图片或 PDF，最大 20MB）
  word_media_type    image（默认）或 pdf
  grammar_file       语法教案
  grammar_media_type image 或 pdf
  word_ref_key / grammar_ref_key   已有教案 key（有 file 时忽略）

兼容：若只传一个 file（旧写法），会给单词条和语法条各绑一份教案（不推荐）。


2）JSON（无文件时）

{
  "course_label": "标日初级上册第23课",
  "word_content": "東, 西, 南, 北",
  "word_meanings": "东|西|南|北",
  "grammar_content": "～によると, ～について",
  "grammar_meanings": "据……说|关于……"
}


成功响应示例
------------
{
  "ok": true,
  "course_label": "标日初级上册第23课",
  "course_group_id": "cg_m5abc_x7k2",
  "word_lesson": { "id": 101, "kind": "word", "course_label": "标日初级上册第23课", "…": "…" },
  "grammar_lesson": { "id": 102, "kind": "grammar", "course_label": "标日初级上册第23课", "…": "…" },
  "lessons": [ /* word_lesson, grammar_lesson */ ],
  "word_ref_key": "lesson-101",
  "grammar_ref_key": "lesson-102",
  "word_ref_view_path": "/api/jp-vocab/ref/lesson-101",
  "grammar_ref_view_path": "/api/jp-vocab/ref/lesson-102"
}


失败响应
--------
401  { "ok": false, "error": "Unauthorized" }
400  course_label_required / word_content_required / grammar_content_required
400  word_content_empty / grammar_content_empty / …
413  File too large (max 20MB)
500  服务器异常


curl 示例（单词教案 + 语法教案）
--------------------------------
curl -sS -X POST 'https://japanese.info-quests.com/api/jp-lesson/upload-mixed' \
  -H 'Authorization: Bearer 你的TOKEN' \
  -F 'course_label=标日初级上册第23课' \
  -F 'word_content=東, 西, 南, 北' \
  -F 'word_meanings=东|西|南|北' \
  -F 'grammar_content=～によると, ～について' \
  -F 'grammar_meanings=据……说|关于……' \
  -F 'word_media_type=image' \
  -F 'word_file=@lesson23-words.png' \
  -F 'grammar_media_type=image' \
  -F 'grammar_file=@lesson23-grammar.png'


Python 最小示例（JSON，无文件）
-----------------------------
import json
import urllib.request

URL = "https://japanese.info-quests.com/api/jp-lesson/upload-mixed"
TOKEN = "你的TOKEN"

payload = {
    "course_label": "标日初级上册第23课",
    "word_content": "東, 西, 南, 北",
    "grammar_content": "～によると, ～について",
}

req = urllib.request.Request(
    URL,
    data=json.dumps(payload, ensure_ascii=False).encode("utf-8"),
    headers={
        "Authorization": f"Bearer {TOKEN}",
        "Content-Type": "application/json",
    },
    method="POST",
)

with urllib.request.urlopen(req, timeout=60) as resp:
    data = json.loads(resp.read().decode("utf-8"))

print(data["course_label"], data["course_group_id"])
print("word_id=", data["word_lesson"]["id"], "grammar_id=", data["grammar_lesson"]["id"])


上传后页面行为
--------------
1. `/jp-lesson` 出现两条新课（默认未完成）：
   - 类型「单词」+ 教材「标日初级上册第23课」
   - 类型「语法」+ 教材「标日初级上册第23课」
2. 旧数据（单传 / 历史上传）教材列为空「—」，不受影响。
3. 分别标「已完成」后：
   - 单词进抽问（不写释义），语法进抽问（写释义）；例句有则写入
   - **course_label 一并写入词条**；抽问/带读/学生/复习卡片**靠后**（熟悉程度/统计之后）显示弱标签，如「标日初级上册第23课」
