英语抽背 · 词表读取 / 熟悉程度 / 同步学生 API
============================================

用途
----
网页主路径与其它项目可按同约定调用：

1) GET /api/en-vocab
   - 无 query：全库列表（**瘦身**：不含备注/用法/例句/接序正文）
   - ?word_id=N：单条详情（**含** usage / example_sentences / connection 正文）

2) POST /api/en-vocab
   - 整词勾选：`level`
   - 或按用法勾齐：`usage_levels`（有编号用法时）
   → **只写熟悉程度 / 用法档**，不同步学生
   - 管理员另可：`set_daily_quiz_target` / `daily_quiz_style` / `reset` / `reset_today`

3) POST /api/en-vocab/share
   把该词同步到学生「今日背英语单词」→ **每词今日只成功一次**
   （产品约定：老师点「下一个」/「完成抽查」时再调；已共享则勿重复发）

说明：勾选 / 用法勾齐 **不会** 再自动 shareToStudy。学生端自动弹卡依赖 share 成功
（或学生 peek「查看老师正在抽查的单词」）。


线上地址
--------
GET  https://english.info-quests.com/api/en-vocab
GET  https://english.info-quests.com/api/en-vocab?word_id=45
POST https://english.info-quests.com/api/en-vocab
POST https://english.info-quests.com/api/en-vocab/share

说明：也可用 finance.info-quests.com 同路径（同一 Worker / 同一 D1）。


本机开发（可选）
---------------
GET/POST http://127.0.0.1:3002/api/en-vocab
POST     http://127.0.0.1:3002/api/en-vocab/share


鉴权
----
须登录 Cookie 会话：
- GET：英语词表读权限（老师 / 管理员）
- POST 勾选 / share：英语 operate（或管理员）
- POST set_daily_quiz_target / daily_quiz_style / reset*：管理员

Header（可选，影响错误文案语言）：
  x-locale: zh | en
  Content-Type: application/json   （仅 POST）

重要（1102）
------------
- 全库列表 **不返回** `class_notes` / `usage` / `example_sentences` / `connection` 正文。
- 用 `*_present`（如 `usage_present`）判断「有没有内容」；需要正文时再调
  `GET ?word_id=` 或 `GET /api/en-vocab/class-notes?word_id=`（备注）。
- **禁止**为展示用法/例句再全表扫大字段。

--------
401  { "ok": false, "error": "…" }   // 未登录

Python 最小例

BASE = "https://english.info-quests.com"

────────────────────────────────
POST · 勾选熟悉程度（不共享）
────────────────────────────────

请求体（二选一）
----------------
整词三档：
{
  "word_id": 45,
  "level": "weak"   // very | normal | weak
}

有编号用法（须全部勾齐后再 POST）：
{
  "word_id": 45,
  "usage_levels": ["very", "normal"]
}


成功响应（节选）
----------------
{
  "ok": true,
  "word": { "id": 45, "word": "…", "last_review_level": "…",
            "last_usage_levels": "…", … },
  "shared": false,
  "shared_new": false
}

说明：
- 当前实现固定 **不** 在勾选时写入今日共享；`shared` / `shared_new` 一般为 false。
- 勿再假定「勾齐用法 = 已同步给学生」。
- 响应里的 word 多为列表形（大字段可能省略）；本地已拉过的正文勿被 null 冲掉。


失败响应
--------
401  { "ok": false, "error": "…" }
400  { "ok": false, "error": "level_invalid" }
400  { "ok": false, "error": "usage_levels_invalid" }
400  { "ok": false, "error": "usage_levels_count_mismatch" }
400  { "ok": false, "error": "review_locked" }   // 勾选已满 1 小时等
404  { "ok": false, "error": "not_found" }

---------
# 整词
curl -sS -X POST 'https://english.info-quests.com/api/en-vocab' \

  -H 'Content-Type: application/json' \
  -H 'x-locale: zh' \
  -d '{"word_id":45,"level":"normal"}'

# 按用法（须与编号用法条数一致）
curl -sS -X POST 'https://english.info-quests.com/api/en-vocab' \
  -H 'Cookie: 你的登录 Cookie' \
  -H 'Content-Type: application/json' \
  -H 'x-locale: zh' \
  -d '{"word_id":45,"usage_levels":["very","normal"]}'

────────────────────────────────
POST · 同步给学生（今日共享）
────────────────────────────────

请求体
------
{
  "word_id": 45
}


成功响应（节选）
----------------
{
  "ok": true,
  "word": { … },
  "item": { … }   // 若有，共享列表项
}


失败响应
--------
401 / 403  未登录或无权共享
400  { "ok": false, "error": "word_id_invalid" }

推荐调用顺序（对齐老师端抽查卡）
--------------------------------
1. 进页：GET /api/en-vocab 拉瘦身列表
2. 打开用法弹窗 / 抽查卡：GET /api/en-vocab?word_id=N 补正文（备注另走 class-notes）
3. 用法/熟悉程度勾完 → POST /api/en-vocab 写库（不共享）
4. 老师点「下一个」→ 若今日未共享 → POST /api/en-vocab/share
5. 已共享（或 409 already_shared_today）→ 直接进下一词，勿重复 POST share
