# 日语复习 · 微信小程序

独立小程序，只包含 **日语复习**（`/jp-vocab/review`）功能：选数量、按序号/抽查优先级排序、卡片复习、清除已复习。与网页端共用同一套 API 与 D1 复习进度（`jp_vocab_review_done`）。

## 目录结构

```
wechat-jp-vocab-review/
├── app.js / app.json / app.wxss
├── config.js              ← 线上 API 域名
├── project.config.json    ← 微信开发者工具项目配置
├── pages/
│   ├── login/             管理员登录
│   ├── index/             复习设置 + 词条列表
│   └── flashcard/         复习卡片（大按钮：上一个 / 下一个）
└── utils/                 与网页端对齐的排序/进度逻辑
```

## 接下来你要怎么做

### 1. 注册并创建小程序

1. 打开 [微信公众平台](https://mp.weixin.qq.com/) → 小程序 → 注册（个人或企业主体均可用于自用）。
2. 记下 **AppID**（开发 → 开发管理 → 开发设置）。

### 2. 配置本项目

1. 用 **微信开发者工具** 打开本文件夹：  
   `strategy-compare-cloud/wechat-jp-vocab-review`
2. 编辑 `project.config.json`，把 `"appid": "请替换为你的小程序 AppID"` 改成你的 AppID。
3. 编辑 `config.js`，确认 `BASE_URL` 为你的线上域名，例如：  
   `https://finance.info-quests.com`

### 3. 配置服务器域名（必做）

在微信公众平台 → 开发 → 开发管理 → 开发设置 → **服务器域名**：

| 类型 | 域名 |
|------|------|
| request 合法域名 | `https://finance.info-quests.com`（与 `config.js` 一致，**不要**带路径） |

说明：

- 小程序通过 Cookie 维持登录（与网页同一套 `/api/english-teacher-review/auth`）。
- 域名必须 **HTTPS**，且已在微信后台备案校验通过。
- 本地调试可在开发者工具中勾选「不校验合法域名」；真机预览/上线必须配好域名。

### 4. 确保后端已部署

网页端 **日语复习** 相关接口需已上线（本次仓库改动）：

- `GET /api/jp-vocab` — 词表
- `GET /api/jp-vocab/review` — 复习进度
- `POST /api/jp-vocab/review` — `review_next` / `clear`
- `GET/POST /api/english-teacher-review/auth` — 登录

仅 **admin** 账号可登录小程序。

### 5. 本地调试

1. 微信开发者工具 → 导入项目 → 选择 `wechat-jp-vocab-review` 目录。
2. 开发阶段可勾选：**详情 → 本地设置 → 不校验合法域名**。
3. 编译运行 → 用管理员账号登录 → 测试开始复习、下一个、清除已复习。
4. 卡片页底部 **「上一个」「下一个」** 按钮较高（约 96rpx），减少误触。

### 6. 真机预览

1. 服务器域名配置完成后，取消「不校验合法域名」。
2. 开发者工具 → **预览** → 手机微信扫码。
3. 确认与网页端复习进度同步（同一 admin 账号）。

### 7. 上传与发布

1. 开发者工具 → **上传** → 填写版本号与备注。
2. 公众平台 → 版本管理 → 提交审核（说明：内部日语学习复习工具，仅管理员使用）。
3. 审核通过后 **发布**。

若仅自己使用，也可在「体验版」或「开发版」中长期使用，不必公开发布。

## 功能说明

| 页面 | 功能 |
|------|------|
| 登录 | 管理员用户名/密码，与网站相同 |
| 首页 | 复习数量、排序方式、词条列表、开始/继续/清除 |
| 卡片 | 单词/释义/巧记/备注/熟悉程度/统计；上一个、下一个、关闭 |

小程序 **不提供** 编辑词条、发给学生、教案查看等（仍在网页 `/jp-vocab` 操作）。

## 常见问题

**登录失败 / 403**  
- 确认账号为 admin 角色。  
- 确认 `BASE_URL` 与 request 合法域名一致。  
- 真机需 HTTPS 且域名已在微信后台配置。

**请求失败**  
- 检查 Cloudflare / 站点是否允许小程序 User-Agent 访问（一般无特殊限制）。  
- 开发者工具 Network 面板查看具体 HTTP 状态码。

**进度与网页不一致**  
- 两端须同一 admin 账号；复习进度存 D1，不存手机本地（仅复习数量/排序偏好存本地 Storage）。

## 与主仓库关系

- 小程序代码 **独立目录**，不影响 Next.js 构建。
- 业务逻辑复制自 `src/lib/jp-vocab-review-*.ts`，后端无额外改动即可对接。
- 若以后改 API，需同步更新 `utils/api.js` 与相关页面。
